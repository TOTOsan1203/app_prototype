# シュート撮影ガイド（試作版 PWA）

iPhoneのSafariで開き、ホーム画面に追加して使う撮影ガイドです。
撮影した動画はiPhoneの中だけで扱い、どこにも送信しません。

## 中身
- index.html … アプリ本体（カメラ、人型の枠、骨格認識、チェック、音声案内、自動録画）
- manifest.webmanifest / sw.js … ホーム画面に追加して起動するための設定
- icon-*.png … アイコン

## iPhoneで使うには
カメラを使うため、HTTPSのURLで公開する必要があります（ファイルを直接開いてもカメラは動きません）。
例：GitHub Pages で、このフォルダの中身をそのまま公開する。
公開したURLをiPhoneのSafariで開き、共有ボタン →「ホーム画面に追加」。

## 試作版の制限
- ブラウザの制限で、撮影は最大60fps程度（240fpsはiPhoneアプリ版で対応予定）
- 人の認識モデルは初回にネットから読み込みます
